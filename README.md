# トレンド羅針盤（trend-rashinban） 導入手順書

ジャンルを選ぶと、いまの流行を AI が 2 軸の 4 象限マップにし、性格診断で「★ あなたの現在地」を重ねて表示する Web アプリです。気になった流行は記録してカレンダーで振り返り、たまった記録から AI が関心の傾向を分析します。

## ファイル構成

```
trend-rashinban/
├── index.html      画面（認証・マップ・カレンダー・傾向分析・各モーダル）
├── style.css       デザイン（PC／スマホ対応、ダークモード対応）
├── app.js          画面の動き（SVG マップ、ドリルダウン、TTS、診断、記録）
├── config.js       GAS の URL・バージョン・ジャンル一覧などの設定
├── README.md       この手順書
└── gas/
    └── Code.gs     GAS バックエンド（認証・Gemini 呼び出し・DB）
```

GitHub Pages に置くのは `index.html` `style.css` `app.js` `config.js` の 4 つです。`gas/Code.gs` は GAS エディタに貼り付けます（リポジトリに置いても動作には影響しません）。

## 1. スプレッドシートと GAS の準備

1. Google ドライブで新しいスプレッドシートを作り、名前を「トレンド羅針盤 DB」などにします。
2. メニューの「拡張機能 → Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`gas/Code.gs` の内容を貼り付けて保存します。
4. 関数の選択欄で `setup` を選んで「実行」します。初回は権限の承認画面が出るので、自分のアカウントで許可してください。
   - シート（Users / Trends / History / Profiles / Reports / Assets）が作られます。
   - Drive に「トレンド羅針盤_data」フォルダが作られます（トレンド JSON と分析レポート JSON の保存先）。
   - パスワード用の PEPPER などのスクリプトプロパティが自動で入ります。

## 2. スクリプトプロパティの設定

「プロジェクトの設定（歯車）→ スクリプト プロパティ」で次を確認・設定します。

| キー | 内容 | 既定値 |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio で発行した API キー（必須） | なし |
| `GEMINI_MODEL` | トレンド抽出・診断・分析に使うモデル | `gemini-2.5-flash` |
| `GEMINI_TTS_MODEL` | 読み上げ用モデル | `gemini-2.5-flash-preview-tts` |
| `TTS_VOICE` | 読み上げの声（config.js 側の指定が優先） | `Kore` |
| `USE_SEARCH_GROUNDING` | Google 検索で最新情報を確認してから地図を作るか | `true` |
| `TREND_ITEMS` | 1 枚の地図に載せるアイテム数の既定値 | `14` |
| `SHOW_TEMP_PASSWORD` | 仮パスワードを画面にも表示するか（テスト用） | `false` |
| `APP_URL` | 仮パスワードのメールに載せるアプリの URL | 空 |
| `THINKING_BUDGET` | 応答を速くしたいときに `0` などを設定（任意） | 空 |

- `PEPPER` は自動設定されます。**後から変えると全員のパスワードが使えなくなる**ので触らないでください。
- モデル名は Google 側の提供状況で変わります。新しいモデルに切り替えるときは `GEMINI_MODEL` と `GEMINI_TTS_MODEL` を書き換えるだけで済みます。
- 設定後、関数 `testGemini` を実行してログに「こんにちは」が出れば Gemini との接続は OK です。

## 3. GAS をウェブアプリとしてデプロイ

1. 右上の「デプロイ → 新しいデプロイ」を開き、種類で「ウェブアプリ」を選びます。
2. 「次のユーザーとして実行」は **自分**、「アクセスできるユーザー」は **全員** にします。
3. デプロイして表示された URL（`https://script.google.com/macros/s/…/exec`）をコピーします。

**コードを変更したときは、必ず「デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」で更新してください。** 保存しただけでは公開中のアプリに反映されません。URL は変わりません。

## 4. config.js の設定

```js
GAS_URL: 'https://script.google.com/macros/s/（コピーしたID）/exec',
VERSION: 'v1.0.0',
```

バージョン番号は画面下のフッターに表示されます。更新のたびに上げておくと、スマホのキャッシュが残っていないかの確認に使えます。ジャンル候補（`GENRES`）、地図のアイテム数（`GEMINI.TREND_ITEMS`）、読み上げの声（`GEMINI.TTS_VOICE`）もここで変えられます。

## 5. GitHub Pages への配置

1. GitHub で `trend-rashinban` リポジトリを作ります。
2. `index.html` `style.css` `app.js` `config.js`（必要なら `README.md` と `gas/`）をリポジトリのルートにアップロードします。
3. 「Settings → Pages」で Branch を `main` / `/(root)` にして保存します。
4. 数分後に `https://kenken6291.github.io/trend-rashinban/` で開けます。
5. スクリプトプロパティ `APP_URL` にこの URL を入れておくと、仮パスワードのメールにリンクが載ります。

## 6. Google Drive と Earth Studio 映像の連携（任意）

アウトドア・ロケ地・旅行系の流行では、ドリルダウン画面に「現地を空から見る」枠が出ます。標準では航空写真と「Google Earthで見る」「地点をKMLで保存」「Earth Studioを開く」ボタンが表示されます。

Google Earth Studio で作ったフライスルー動画を表示したい場合:

1. 「地点をKMLで保存」で書き出した KML を Earth Studio に読み込み、動画を書き出します。
2. 動画（または画像）を Drive に置き、共有設定を **「リンクを知っている全員が閲覧可」** にします。
3. スプレッドシートの `Assets` シートに 1 行追加します。

| keyword | genre | driveFileId | type | note |
|---|---|---|---|---|
| 富士山 | アウトドア | 1AbC…（ファイルID） | video | 富士山ご来光ルートを空から |

- `keyword` が流行アイテム名に含まれていると表示されます。`*` にするとそのジャンルの全アイテムで表示されます。
- `genre` を空にすると全ジャンルが対象になります。
- ファイル ID は Drive の共有リンク `https://drive.google.com/file/d/【ここ】/view` の部分です。

## 7. 動作の流れと確認ポイント

1. **新規登録**：ニックネームとメールアドレスを入れると仮パスワードがメールで届きます（メール送信に失敗したときだけ画面にも表示）。
2. **初回ログイン**：仮パスワードでログインすると、パスワード変更画面が閉じられない状態で出ます。英字と数字を含む 8 文字以上に変更します。
3. **パスワード忘れ**：メールアドレスを入れると新しい仮パスワードが届き、次回ログイン時に再び変更を求められます。
4. **ログイン失敗**：5 回続けて失敗すると 30 分ロックされます。
5. **流行の地図**：同じジャンル・同じ日の地図は `Trends` シートに保存され、2 回目からはすぐ表示されます（「最新の情報で作り直す」で再生成）。
6. **ドリルダウン**：番号の点をタップするとそのアイテム、何もない場所をタップするとその周辺の流行を AI が深掘りします。「音声で聞く」で読み上げます。
7. **性格診断**：AI がジャンルの軸に合わせた質問を 4 問作ります（失敗時は軸に沿った基本の質問に切り替え）。結果の位置に ★ が立ち、近い流行と対角線の流行を提案します。
8. **記録とカレンダー**：「気になる／チェックした／体験した」で記録し、カレンダーの日付から見返したり日記を書き足したりできます。
9. **傾向分析**：記録が 3 件以上になると、関心の傾向と次に試したいジャンルを AI が提案します。

## 8. 困ったとき

| 症状 | 確認すること |
|---|---|
| 「サーバーにつながりませんでした」 | config.js の `GAS_URL`、デプロイの「アクセスできるユーザー：全員」 |
| 「サーバーの応答を読み取れませんでした」 | GAS の再デプロイ（新バージョン）、権限の承認が済んでいるか |
| 「GEMINI_API_KEY が設定されていません」 | スクリプトプロパティのキー名と値 |
| 「AIの呼び出しに失敗しました（404）」 | `GEMINI_MODEL` などのモデル名が現在も提供されているか |
| 「AIが混み合っています」 | 無料枠の上限。少し時間をおくか、`USE_SEARCH_GROUNDING` を `false` に |
| 音声が鳴らない | `GEMINI_TTS_MODEL` のモデル名、スマホのマナーモード |
| 仮パスワードのメールが届かない | 迷惑メールフォルダ、GAS の 1 日あたりのメール送信上限。テスト中は `SHOW_TEMP_PASSWORD` を `true` に |
| 地図の作成が遅い | 検索付き生成は 20〜60 秒かかります。`THINKING_BUDGET` を `0` にすると速くなる場合があります |

## スプレッドシートの構成

- **Users**：email / nickname / salt / hash / mustChange / failCount / lockUntil / status / createdAt / updatedAt / lastLoginAt（`status` を `disabled` にすると利用停止）
- **Trends**：date / genre / json / createdAt / createdBy（ジャンル別・日別のマップ）
- **History**：id / email / date / genre / itemName / summary / status / memo / x / y / createdAt / updatedAt（記録と日記）
- **Profiles**：性格診断の結果履歴
- **Reports**：傾向分析レポート
- **Assets**：Earth Studio 映像などの Drive ファイル登録
